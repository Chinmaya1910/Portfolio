Bachelor’s team project

Water quality prediction for smart mariculture.

An academic exploration of remote sensing and machine learning for water-quality monitoring in marine aquaculture.

Role
Project team member
Context
B.E. final project · New Horizon College of Engineering · 2021–22
Topics
Water-quality sensors, ESP32, data preprocessing, classification

Problem

Water quality in marine aquaculture changes over time. The team explored how remote measurement could make parameters such as pH and turbidity easier to monitor.

Team approach

The team documented a sensing pipeline and a classification workflow. The design described collecting readings using an ESP32-based setup and preparing a dataset for models such as logistic regression and random forests.

Outcome

The final project report records the proposed architecture, hardware choices, and model workflow.
