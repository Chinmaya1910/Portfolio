Student employment · Hochschule Heilbronn

Fluid simulation tool.

A Python desktop application for configuring multi-layer fluid simulations and validating their output.

Role
Student Assistant · Nov 2025 – Feb 2026
Organization
Hochschule Heilbronn
Stack
Python, PySide6 (Qt), QThreadPool, QRunnable, Matplotlib

Problem

Researchers needed to configure simulations with interdependent parameters, run computationally intensive models, and compare results with reference data.

My contribution

I developed the modular desktop application and used QThreadPool and QRunnable to run calculations off the interface thread. Qt signals and slots validated relationships such as density and viscosity ratios as users changed inputs.

Result

The application kept the interface responsive during calculation. An embedded Matplotlib dashboard let researchers compare simulation output and reference data side by side.
