Professional project · More Retail

ONDC seller integration.

A serverless seller backend that connected More Retail to India’s Open Network for Digital Commerce.

Role
Software Development Engineer I
Organization
More Retail Private Limited · Bengaluru, India
Stack
Python, Flask, AWS Lambda, API Gateway, PostgreSQL

Problem

More Retail needed to participate in ONDC as a seller network participant. The integration required a backend that could connect the seller application to the network.

My contribution

I designed and implemented the backend integration and migrated the existing Flask seller application to AWS Lambda and API Gateway, with PostgreSQL for persistence.

Outcome

More Retail joined ONDC as a seller. The current résumé records a twofold rise in regional grocery orders in Bengaluru within three to four weeks of launch.
