Master’s thesis · In progress

QueryBlocks.

A block-based interface for inspecting and correcting AI-generated business intelligence queries.

Context
M.Sc. Thesis · Hochschule Heilbronn
Research focus
Block-Based User Interfaces for Human–AI Collaboration in Business Intelligence
Stack
React, Blockly, FastAPI, SQLGlot, DuckDB

Problem

A natural-language request can produce SQL that runs successfully while applying the wrong country or period filter. A business user needs a way to inspect what the system understood and correct the specific field that is wrong.

What I built

The prototype parses supported SQL into a typed query representation. Users can inspect the query summary and edit fields such as measure, country, and quarter in Blockly. The FastAPI backend validates the draft, compiles parameterized SQL, and executes it against a read-only DuckDB dataset. A block edit can run without another model call.

Current status

The retail profile runs on 319,227 cleaned invoice lines from Daqing Chen’s UCI Online Retail dataset. The technical evaluation checked eight reference filter repairs against independent SQL. The prototype supports a bounded set of single-table queries, and the user study is in preparation.
